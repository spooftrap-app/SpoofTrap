## 2024-05-15 - Command Injection in Application Bundle Path
**Vulnerability:** The application was vulnerable to command injection because `Bundle.main.bundleURL.path` was directly interpolated into a `/bin/sh -c` command without sanitization. In macOS, users can arbitrarily rename application bundles (e.g., `SpoofTrap"; rm -rf /; ".app`), which would execute arbitrary commands with the privileges of the running application when relaunched.
**Learning:** Even internal bundle properties like the app's file path are user-controllable input and must not be trusted in shell commands. The application launch logic requires using `/bin/sh -c` with `sleep` to allow the current process to terminate before `open` locks the binary again.
**Prevention:** Always use safe argument passing mechanisms like `$1` and the `--` delimiter to map user-controlled paths as secure positional arguments when using `/bin/sh -c` via Swift's `Process` APIs, rather than unsafe string interpolation.
