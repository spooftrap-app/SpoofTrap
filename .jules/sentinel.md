## 2024-05-31 - [Input Validation for Extracted Log Data]
**Vulnerability:** Command/Argument Injection and SSRF risk via unvalidated logs. PIDs, IP Addresses, and Place IDs were parsed dynamically from untrusted strings (Roblox log files) and passed directly into sub-processes (e.g. `ping`) or as external network requests (e.g. `https://games.roblox.com` or `http://ip-api.com`).
**Learning:** Application logs should be treated as untrusted input just like web forms. An attacker could intentionally trigger specific log formats (e.g. with manipulated names, spoofed IDs) causing the log watcher to parse invalid data which is then directly executed by standard utilities, resulting in shell injection, execution errors, or SSRF risks depending on context.
**Prevention:** Always validate all extracted log fields using strictly defined regular expressions (e.g., `^[0-9]+$` for PIDs, `^[a-fA-F0-9.:]+$` for IPs) before incorporating them in sub-process calls or URL interpolations.
