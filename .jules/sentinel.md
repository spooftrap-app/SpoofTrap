## 2024-05-24 - SSRF and Argument Injection via Log Parsing
**Vulnerability:** Extracted inputs from local log files (such as Place IDs, IP addresses, and Process IDs) were being directly interpolated into external API network request URLs (`URLSession.shared.data(from:)`) and shell commands passed to `Process().arguments` (e.g., `ping`, `ps`) without format validation. An attacker capable of manipulating the log contents could inject malicious characters, leading to Server-Side Request Forgery (SSRF) or Argument Injection.
**Learning:** Data extracted from local files, even application logs, must be treated as untrusted input. Variables like `pid`, `placeId`, and `ip` can be manipulated and therefore must be strictly validated before use in sensitive sinks, such as shell commands or network requests.
**Prevention:** Implement strict format validation via regular expressions immediately after extracting data from untrusted sources, before it is used in subsequent operations. For example, ensure IP addresses match `^[a-fA-F0-9.:]+$`, and numeric identifiers like Place IDs and PIDs match `^[0-9]+$`.
