## 2024-06-14 - Fix Local Command Injection via Bundle Path Interpolation
**Vulnerability:** A local command injection risk existed in `UpdateChecker.swift` where `Bundle.main.bundleURL.path` was directly interpolated into a shell command `["-c", "sleep 1 && open \"\(appPath)\""]`. A user could execute arbitrary commands if the application was placed in a directory with a maliciously crafted name containing shell metacharacters (e.g. quotes or semicolons).
**Learning:** Even internal API paths like `Bundle.main.bundleURL.path` can be user-controllable (as the user can rename the application directory). Directly interpolating these paths into strings executed by `sh` is dangerous.
**Prevention:** Always pass user-controllable or dynamic paths as separate arguments to the shell execution (e.g., passing the path as an argument to be accessed via `$0` or `$1` inside the shell script: `["-c", "sleep 1 && /usr/bin/open \"$0\"", appPath]`). Additionally, prefer absolute paths for system binaries (`/usr/bin/open` instead of `open`) to mitigate PATH manipulation risks.
