## 2024-05-24 - Command Injection via Bundle Path Interpolation
**Vulnerability:** Command injection vulnerability identified when utilizing `Process()` to execute shell commands `/bin/sh -c`. The application path (`Bundle.main.bundleURL.path`) was being directly interpolated into the shell command string (`"sleep 1 && open \"\(appPath)\""`). Since application paths are user-controllable (e.g., a user can rename the application bundle), a maliciously crafted app name could inject arbitrary commands.
**Learning:** Even internal variables like application bundle paths must be treated as untrusted input. Direct string interpolation into shell commands bypasses the safety mechanisms of `Process.arguments`.
**Prevention:** Always pass user-controllable variables as separate positional arguments when using `/bin/sh -c`. Construct the shell script string with positional placeholders (e.g., `"$1"`) and pass the actual variable in the `Process.arguments` array, separated by a delimiter `--` (e.g., `["-c", "sleep 1 && /usr/bin/open \"$1\"", "--", appPath]`).
