## 2024-05-31 - Command Injection via String Interpolation in Shell Commands
**Vulnerability:** The application was using unsafe string interpolation (`"\(appPath)"`) to pass dynamic data (the app's path) to an external bash shell (`/bin/sh -c`). If `appPath` contained shell metacharacters like semicolons or quotes, a malicious actor could execute arbitrary commands.
**Learning:** String interpolation should never be used to construct shell commands when executing them via `Process()`, especially when calling a shell like `/bin/sh` that evaluates metacharacters. Even ostensibly safe variables like a bundle URL path can be manipulated by users renaming the application directory.
**Prevention:** When a shell is strictly required (e.g., for backgrounding tasks across application termination), pass dynamic parameters as separate positional arguments to the shell script itself (e.g., passing `$0`, `$1`, etc. in the script string, and providing the user data as subsequent arguments in the `Process.arguments` array).
