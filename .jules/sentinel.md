## 2024-05-17 - Argument Injection and SSRF Risks in Log Parsers
**Vulnerability:** Untrusted input extracted from application log files (such as PIDs or IP addresses) was passed directly into arguments for shell processes (e.g., `ps`, `ping`) and as path components for external API requests (e.g., `ip-api.com`). This poses risks of argument injection (e.g., if an attacker crafts a log entry that tricks the parser into extracting a command flag instead of a clean PID) and SSRF.
**Learning:** Even though macOS `Process()` doesn't evaluate via a shell by default (preventing classical shell injection with `;`), it is still vulnerable to argument injection if input starts with a hyphen or contains spaces. Similarly, using untrusted input in URLs without validation can allow for arbitrary endpoints to be hit or query parameters to be manipulated.
**Prevention:** Always validate extracted log data against a strict regular expression format (e.g., `^[0-9]+$` for PIDs, `^[a-fA-F0-9.:]+$` for IPs) before utilizing it in sensitive operations or URL path construction.
